# Arquivo histórico

Esta pasta preserva ADRs e relatórios produzidos durante as etapas anteriores. Seu conteúdo registra o contexto de cada momento e pode conter pendências já resolvidas, decisões substituídas, números de testes antigos e instruções operacionais circunstanciais.

Para desenvolvimento, use sempre os documentos canônicos na pasta superior:

- [Índice](../README.md)
- [Regras de negócio](../REGRAS_NEGOCIO.md)
- [Arquitetura](../ARQUITETURA.md)
- [Funcionalidades](../FUNCIONALIDADES.md)
- [Histórico consolidado](../HISTORICO.md)

Consulte os arquivos deste diretório apenas quando for necessário investigar a origem de uma decisão ou a evidência de uma etapa específica.
