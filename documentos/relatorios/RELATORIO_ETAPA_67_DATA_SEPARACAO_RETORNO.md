# Etapa 67 — Data na separação para retorno

Os cards da separação imediata passaram a exibir a data de fabricação ao lado do lote, no formato compacto `Lote CICINV · 09/09/2026`, facilitando identificar o item ao informar a quantidade de retorno.

A interface reutiliza a data já recebida pela API e o formatador de datas civis existente. Não houve mudança no backend, nas quantidades ou nas regras da separação.
